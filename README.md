# 全港數學思維大激鬥（MathConceptition）歷屆賽題互動複習系統

本專案為**全港數學思維大激鬥（MathConceptition）**歷屆真題打造的互動視覺化投影簡報與題庫解析系統。

---

## 🌟 核心特色 (Core Features)

1. **一頁一題・左題右解・動態探究**：
   - **左欄（試題與考點）**：中英雙語題目題幹、分值佔比、原卷幾何截圖、核心知識點與必背公式。
   - **右欄（動態圖解與解答）**：解題思維導引、符合競賽標準的規範踩點步驟、官方標準答案、速解秒殺訣竅。
2. **三部曲漸進式翻頁體驗**：
   - `① 審題閱讀` ➔ `② 核心考點&公式 (快捷鍵 K)` ➔ `③ 規範解答與速解 (快捷鍵 A)` ➔ 下一題。
3. **三大全螢幕放大功能**：
   - 🔍 **放大題目 (Q)**：全黑板超大字體呈現題幹與幾何配圖。
   - 🔍 **放大知識點 (K)**：全黑板呈現必背公式、破題切入點與易錯盲區。
   - 🔍 **放大解答 (A)**：滿版呈現解題步驟，方便老師踩點精講。
4. **授課教具一應俱全**：
   - 虛擬紅色雷射筆（快捷鍵 `L`，含動態拖尾效果）。
   - 多色板書畫筆（快捷鍵 `P`）、橡皮擦、一鍵清除筆跡（快捷鍵 `C`）。
   - 支援投影全螢幕切換。
5. **教師進度管理與大螢幕掃碼**：
   - 教師 PIN 碼（預設 `8888`）自由開放指定試卷。
   - 支援向量 QR 碼，學生使用 iPad / 手機相機掃描即可同步進入指定試卷。
